Что такое таблица LR(k) КС-грамматики
________________________________________________________________
Каждая LR(k) таблица представляет собой пару функций <f, g>. Функция действия f устанавливает, какое действие надо предпринять. Действием может быть: 
1. Перенос очередного входного символа в магазин;
2. Сворачивание содержимого верхней части магазина в соответствии с известным правилом;
3. Сообщение об окончании разбора;
4. Сообщение о том, что во входной цепочке найдена синтаксическая ошибка. 
Вторая функция, а именно функция перехода g, вызывается после каждого переноса и каждой свертки. Функция перехода по символу грамматики либо определяет имя другой таблицы, либо выдаёт код ошибки.
================================================================
Что такое множество LR(k) таблиц КС-грамматик
________________________________________________________________
Множеством LR(k) таблиц для КС-грамматики G называют пару (T, T0), где T - совокупность таблиц для G, а таблица T0, принадлежащая T, начальная.
================================================================
Что такое конфигурация LR(k) анализатора для множества LR(k) таблиц КС-грамматик
________________________________________________________________
Пусть (T, T0) - множество LR(k)-таблиц для LR(k) грамматики G = (N, Σ, P, S). Қонфигурацией LR(k)-анализатора для 
(T, T0) назовем тройку (T0 X1T1 ... XmTm, w, π), где:
1. Ti принадлежит T, 0 <= i <= m и T0 - начальная таблица;
2. Xi принадлежит N ⋃ Σ, 1 <= i <= m;
3. w принадлежит Σ*;
4. π - выходная цепочка, состоящая из номеров правил.
Первая компонента конфигурации представляет содержимое магазина, вторая - непросмотренную часть входной цепочки, третья - построенный к этому моменту разбор.
Начальная конфигурация анализатора - это конфигурация вида (T0, w, e) для некоторой цепочки w из Σ*.
================================================================
Приведи алгоритм разбора слова по LR(k) грамматике
________________________________________________________________
Пусть на входе есть КС-грамматика G = (N, Σ, P, S), множество (T, T0) LR(k)-таблиц для G, где T0 - начальная таблица, и входная цепочка w.
Алгоритм разбора LR(k) грамматики:
1. Построить начальную конфигурацию (T0, w, e).
2. Пусть С - последняя построенная конфигурация. Построим такую очередную конфигурацию С', которая получается при переходе из С, и затем повторим шаг 2. Если очередной конфигурации нет, перейдём к шагу 3.
3. Пусть С = (а, х, π) - последняя построенная конфигурация. Где π - построенная последовательность правил, x - оставшаяся часть входной цепочки, a - содержимое магазина.
Если С-допускающая конфигурация, вывести π и остановиться. В противном случае сообщить об ошибке.
Если алгоритм достигает допускающей конфигурации, то выходная цепочка π называется разбором для входной цепочки w.
================================================================
Когда множество LR(k) таблиц называется корректным
________________________________________________________________
Множество LR(k) таблиц называют корректным для КС-грамматики G, если алгоритм разбора порождает корректный разбор для любой цепочки из языка G и не порождает разбора ни для какой цепочки w, не принадлежащей языку G.
================================================================
Что такое эквивалентные множества таблиц LR(k) грамматик
________________________________________________________________
Два множества LR(k) таблиц могут быть по-разному эквивалентны. 
Например, самая слабая эквивалентность означает, что алгоритм разбора, работающий с двумя множествами таблиц, порождает один и тот же разбор для цепочек, принадлежащих языку L(G) грамматики G, и что цепочки, не
анализируемые при использовании одного множества таблиц, не анализируются и при использовании другого множества таблиц. Ошибочные ситуации могут обнаруживаться в разное время.
С другой стороны, самая сильная эквивалентность требует, чтобы при работе с двумя множествами таблиц порождались одинаковые последовательности шагов разбора.
Иными словами, пусть (T0, w, e) и (T0', w, e)- начальные конфигурации для двух множеств таблиц T и T'. Тогда для всех i >= 0 при использовании таблиц из T
(T0, w, e) -> (T0 X1T1 ... XmTm, x, π) тогда и только тогда, когда при использовании таблиц из T' тогда и только тогда, когда при использовании таблиц из (T0', w, e) -> (T0' X1'T1' ... Xn'Tn', x', π'), 
причём m = n, x = x', π = π' и Xi = Xi' для 1 <= i <= m.
================================================================
Что такое φ-недостижимые множества таблиц LR(k) грамматик
________________________________________________________________
Многие из элементов "ошибка" множества LR(k) таблиц,  которые представляют собой ситуации, когда парсер не может продолжать анализ входной строки, потому что не может найти подходящее действие для текущего состояния и следующего символа входа,
никогда не используются алгоритмом разбора LR(k) грамматики. Такие элементы можно заменить элементами ф, действительно несущественными в том смысле, что ни в какой достижимой конфигурации они не влияют на вычисление очередной конфигурации.
Пусть (T, T0) - множество LR(k) таблиц, k >= 1 и C = (T0 X1T1 ... XmTm, w, π) - любая достижимая конфигурация. 
Пусть Tm = <f, g> и u - первые k элементов w. Будем говорить, что в T нет достижимых элементов ф или T ф-недостижимо, если для любой конфигурации C справедливы следующие утверждения:
1. f(u) не равно ф;
2. Если f(u) - перенос, то g(a) не равно ф, где a - первый символ цепочки u;
3. Если f(u) - сворачивание i, то есть правило с номером i есть A -> Y_i ... Y_r, r >= 0 и Tm-r, то есть элемент из множества T с индексом (m - r) = <f', g'>, то g'(A) не равно ф.
================================================================
Что такое исчезающий и неисчезающий символ в КС-грамматике
________________________________________________________________
Нетерминал A называется исчезающим, если из A выводится пустая цепочка. В противном случае символ из N ⋃ Σ назовём неисчезающим. Таким образом, каждый терминал - неисчезающий символ.
