Нормальная форма Розенкранца - это?
________________________________________________________________
Грамматика G = (Σ, N, R, S) находится в нормальной форме Розенкранца, если всякое правило из 
R находится в одном из следующих видов:
A → aαd (a, d ∈ Σ, α ∈ (Σ ∪ N)*)
A → a (a ∈ Σ)
S → ε (только если S не встречается в правых частях никаких правил)
================================================================
Теорема Розенкранца-Энгельфрита
________________________________________________________________
Для всякой контекстно-свободной грамматики существует и может быть эффективно 
построена грамматика в нормальной форме Розенкранца, задающая тот же язык. 
Размер полученной грамматики — O(n^20) относительно размера 
исходной грамматики, и O(n^10), если исходная грамматика находится в нормальной форме Хомского.
================================================================
Лемма Энгельфрита о представлении контекстно-свободных грамматик
________________________________________________________________
Пусть G = (Σ, N, R, S) — обыкновенная грамматика в
нормальной форме Хомского. Тогда грамматика G' = (Σ, N ∪ N' ∪ N'', R', S), 
где N' = { B\A | A, B ∈ N } и N'' = { A/B | A, B ∈ N } (где B\A - это строка вида A, 
с удалённым префиксом вида B, A/B - это строка вида A, с удалённым суффиксом вида B), и множество R'
состоит из следующих правил, задаёт тот же язык, что и G.
A → a (A → a ∈ R)
A → b B\D E/C c (A → DE, B → b, C → c ∈ R)
E\A → F D\B C (A → BC, D → EF ∈ R)
A/F → B C/D E (A → BC, D → EF ∈ R)
B\A → C (A → BC ∈ R)
A/C → B (A → BC ∈ R)
D\D → ε (D ∈ N)
D/D → ε (D ∈ N)
В частности, L(G'(A)) = L(G(A)) для всех A ∈ N, а нетерминальные символы вида A\D и
D/A задают следующие языки.
L(G'(A\D)) = { w | есть дерево Aw из D, где A — дырка, справа от которой — листья w }
L(G'(D/A)) = { w | есть дерево wA из D, где A — дырка, слева от которой — листья w },
================================================================
Ограниченный язык - это?
________________________________________________________________
Язык L - ограниченный, если L ⊆ (w1)*(w2)* ... (wk)* для некоторого конечного множества слов
{w1, w2, ... , wk}
================================================================
Критерий контекстной-свободности для ограниченных языков
________________________________________________________________
Пусть L - ограниченный (т.е. представим словами вида (w1)^k1(w2)^k2 ... (wk)^kn), тогда
каждое слово из L можно представить как вектор вида: (k1, k2, ... kn) ∈ V, где V - множество всех
векторов в языке L.
Период вектора (k1x1 + m1, k2x2 + m2, ... ,knxn + mn) - это (k1, k2, ... kn) стратифицирован, если 
каждый элемент объединения имеет <= 2 ненулевых компонент и для индексов: i<j<k<l не существует
векторов v1, v2, таких что: v1[i] != 0 & v1[k] != 0 & v2[j] != 0 & v2[l] != 0 (т.е. нет перекрестных зависимостей).
Тогда L - контекстно свободный ⇔ множество V является объединением линейных векторов, со стратифицрованными коэффициентами.
================================================================
Теорема Грейбах о самом трудном языке для контекстно-свободных грамматик
________________________________________________________________
Существует алфавит Σ' и контекстно-свободная грамматика G' = (Σ', N', R', S') со свойством, 
что для всякой обыкновенной грамматики G, заданной над любым алфавитом Σ, существует такой 
гомоморфизм h: Σ → (Σ')*, что строка w ∈ (Σ)*
принадлежит языку L(G) тогда и только тогда, когда её образ h(w) принадлежит L(G').
Иными словами, L = ((h)−1)(L(G')), если ε ∉ L, и L = ((h)−1)(L(G') ∪ {ε}), если ε ∈ L.
================================================================
Теорема о нижней оценке размера грамматики в нормальной форме Грейбах
________________________________________________________________
Существует последовательность контекстно-свободных грамматик Gn, для n > 1, где 
каждая грамматика Gn определена над n-символьным алфавитом, находится 
в нормальной форме Хомского и имеет размер Θ(n), в то время как всякая грамматика
в нормальном форме Грейбах, задающая тот же язык, должна иметь не менее n^2
правил.
