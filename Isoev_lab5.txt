Конструкция автомата Глушкова

Алгоритм построения Glushkov(r) 
Строим линеаризованную версию r: r{lin} = Linearize(r). 
Ищем First(r{lin}), Last(r{lin}) и Follow {r{lin}}  (c) для всех c ∈ Σ {r{lin}}. 
Все состояния автомата, кроме начального (назовём его S), соответствуют буквам c ∈ Σ {r{lin}} .
Из начального состояния строим переходы в те состояния, для которых c ∈ First(r{lin}). Переходы имеют вид S c→ c. 
Переходы из состояния c соответствуют элементам d множества Follow {r{lin}} (c) и имеют вид c d → d. 
Конечные состояния — такие, что c ∈ Last(r{lin}), а также S, если ε ∈ L (R).
Теперь стираем разметку, построенную линеаризацией, на переходах автомата. Конструкция завершена.

DPDA(deterministic pushdown automaton)

Определение 
PDA(pushdown automaton) A детерминированный, если: 
если есть переход ⟨q, ε, Z⟩ → . . . , то больше никаких переходов по Z из состояния q нет; 
каждой тройке ⟨q, a, Z⟩, a ∈ Σ, соответствует не больше одной правой части.
DPDA слабее, чем NPDA.
Например, язык {a^(n)b^(m) | n = m ∨ m = 2 ∗ n} не распознается DPDA. DPDA с допуском по пустому стеку ещё слабее — язык {a^n} не может быть распознан DPDA с таким допуском.
Предположим, что существует DPDA, распознающий язык {a^(n)b^(m) | n = m ∨ m = 2 ∗ n}. Тогда после чтения префикса a ^(n)b^(n) слова a ^(n)b^(2n) он должен находиться в финальном состоянии. Далее он должен распознать ровно n букв b. Заменим часть автомата, распознающую этот фрагмент слова, на изоморфную ей, но читающую только буквы c. Получим PDA, распознающий язык { a ^(n)b^(n) } ∪ { a ^(n) b^(n) c^(n)}, не являющийся КС.

Первый способ приведения к GNF(Нормальная форма Грейбах)

1.Нумеруем нетерминалы в правых частях правил в порядке их вхождения; 
2. (по исчерпанию по i, начиная с i = 1) Если имеется правило вида A{i} → B{j}β, где j < i, тогда подставляем вместо B{j} все правые части α{k} правил вида B{j}→ α{k}. 
3. Если после этого все правила имеют вид либо A{i} → aα, a ∈ Σ, либо A{i} → B{j}β, причём i < j, тогда GNF получается последовательной развёрткой B{j} . Существует лексикографический порядок на функциональных символах из N. 
4.Если есть правила вида A{i} → A{i}α, тогда устраняем левую рекурсию. 5 Увеличиваем i, если ещё остались нетерминалы, не приведённые к ГНФ

Второй способ приведения к GNF(Нормальная форма Грейбах)

Алгоритм Блюма–Коха (1999). 
Неформальное описание Рассмотрим язык сентенциальных форм с переписыванием только по левому разбору. Он регулярен, и в конечное состояние его НКА ведут стрелки, помеченные терминалами. 
Для такого языка легко построить инверсный ⇒ множество терминалов-префиксов, которые может породить данный нетерминал.
1.По каждому нетерминалу B строим автомат M{B} = ⟨N{B} ∪ {S{B}}, Σ ∪ N, B{B}, {S{B}}, δ⟩ (SB — новое состояние, NB — множество нетерминалов CFG, индексированное нетерминалом B). Правила перехода δ: 
- ⟨C{B}, E,M⟩ ⇔ M = {D{B} | C → DE ∈ P}; 
-⟨C{B}, a, {S{B}}⟩ ⇔ C → a ∈ P. 
2.Строим реверс к MB, получаем НКА MR B. 
3.Строим грамматику G′ {B} = ⟨N{B} ∪ {S{B}}, Σ ∪ N, R ′ {B}, S{B}⟩ для M^(R){B} с правилами переписывания:
S{B} → aC{B} ⇔ ⟨S{B}, a, C{B}⟩ ∈ δ^R и C{B} ̸= B{B} либо из B{B} есть стрелки в M^(R) {B}; 
S{B} → a ⇔ ⟨S{B}, a, B{B}⟩ ∈ δ^R; 
D{B} → EC{B} ⇔ ⟨D{B}, E, C{B}⟩ ∈ δ^R и C{B} ̸=B{B} либо из B{B} есть стрелки в ^R {B}; C{B} → E ⇔ ⟨C{B}, E, B{B}⟩ ∈ δ^R.

Лемма о генеричности и следствие леммы о генеричности

Пусть M, N — термы λ-исчисления, причем вычисление M не завершается, а N имеет н.ф. Тогда для любого контекста C[ ]
	C[M] = {β} N ⇒ ∀L(C[L] ={β} N)

Следствие леммы о генеричности
Пусть существует комбинатор λx y.E, который возвращает T, если буквальные представления x и y совпадают (в каком-либо смысле), и F иначе. 
Положим Ω = (λx.(x x)) λx.(x x), I = λx.x.
Тогда E Ω I = F, E I I = T, но лемма о генеричности влечет, что ∀N(E N I) = F.
Следовательно, E не определим в чистом λ-исчислении.

От ДКА(детерминированный конечный автомат) к префиксной грамматике

В данном алгоритме рассматривается минимальный ДКА(детерминированный конечный автомат) для языка. 
Ведущими словами для нетерминалов (состояний) q{i} объявим классы эквивалентности w{i} такие, что q{0} w{i} −→ q{i}. 
Для всех стрелок, входящих в q{i} из q{k} и помеченных буквами a{j} , построим правила переписывания: w{i} → w{k}a{j} . 
Начальными словами объявим слова из классов эквивалентности, лежащих в языке автомата.

LR(k)-распознаватели

Грамматика G — LR(k), тогда и только тогда, когда для всех пар сентенциальных форм xy,xy′, 
порождаемых правосторонним разбором, где y, y′ ∈ Σ^(+), таких что xy допускает правую свёртку в префиксе y по правилу ξ1, 
а xy′ — свёртку где угодно по правилу ξ2, и первые kсимволов y и y′ совпадают, ξ1 = ξ2.


	S′ → S 		S → L = R; 	S → R;
	L → id 		L → ∗R 		R → L


Поскольку возникает конфликт вида сдвиг–свёртка при попытке анализа L. Но lookahead у L,
порождённой посредством S → L = R, и посредством S → R;→ L;, будет разный.
Любая LR(k)-грамматика по определению гарантирует однозначный разбор при определённой длине lookahead-строки,
поэтому ни одна грамматика с неоднозначным разбором не является LR(k) ни для какого значения k.

PDA(pushdown automaton) по LR(0)-автомату

Общая конструкция
При каждом сдвиге кладём в стек номер состояния, в которое приходим в конечном автомате.
При каждой свёртке извлекаем из стека n символов, где n — длина правой части β правила A → β, после 
чего переходим в состояние с номером n + 1-ого символа в стеке, подразумевая на ленте символ A.
Совершаем переход по символу A из полученного состояния (этот шаг мы на графе объединили с предыдущим).

Автомат нередуцируемых префиксов и типы состояний автомата

Описание конструкции
Отмеченная позиция в правиле: •. В правиле с правой частью ξ1 . . . ξn есть n + 1 таких позиций.
Правило A → α • Bβ и правило B → •γ — одно и то же множество переходов по символу, не приводящих к редукции ⇒ в одном состоянии.
При чтении элемента правой части сдвигаем • вправо на позицию.

Типы состояний автомата

1.Финальное (свёртка в S′).
2.Не финальное, но свёртка.
3.Сдвиг по символу сентенциальной формы.

Неоднозначные КС-языки

Рассмотрим КС-язык {a^(n)b^(m)c^(m)} ∪ {a^(n)b^(n)c^(m)}. Слова a^(n)b^(n)c^(n) этого языка гарантированно имеют минимум два дерева разбора.

Определение
КС-грамматика G неоднозначная, если существует слово w ∈ L(G) такое, что в G у него больше одного дерева разбора.
КС-язык L существенно неоднозначен, если всякая его грамматика неоднозначна.
