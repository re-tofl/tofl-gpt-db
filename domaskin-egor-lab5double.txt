Детерминизация VPA
________________________________________________________________
Теорема: 
    Для любого VPA M с магазинным алфавитом \tilde{Σ} существует детерминированный VPA M' с магазинным алфавитом \tilde{Σ} такой, что L(M) = L(M').

Доказательство:
    Пусть VPA M = ⟨\tilde{Σ}, Q, Q_{in}, Q_{F}, Γ, δ⟩.

    Построим VPA M' = ⟨\tilde{Σ}, Q', Q'_{in}, Q'_{F}, Γ', δ'⟩, где:
        - Q' = 2^{Q × Q} × 2^{Q},
        - Q'_{in} = {(Id_Q, Q_{in})},
        - Q'_{F} = {(S, R) | R ∩ Q_{F} ≠ ∅},
        - Γ' = {(S, R, a) | (S, R) ∈ Q', a ∈ Σ_{call}},
        - δ' -- функция переходов, причём:
            • Если a ∈ Σ_{int}, то ((S, R), a, (S', R')) ∈ δ', где S' = {(q, q') | ∃q'': (q, q'') ∈ S, (q'', a, q') ∈ δ}, R' = {q' | ∃q ∈ R: (q, a, q') ∈ δ},
            • Если a ∈ Σ_{call}, то ((S, R), a, (Id_Q, R'), (S, R, a)) ∈ δ', где R' = {q' | ∃q ∈ R, γ ∈ Γ: (q, a, q', γ) ∈ δ},
            • Если a ∈ Σ_{ret}, то ((S, R), a, (S′, R′, a′), (S′′, R′′)) ∈ δ′, если (S′′, R′′) удовлетворяет следующим условиям:
                Пусть Update = {(q, q′) | ∃q_1​, q_2 ​∈ Q, γ ∈ Γ: (q, a′, q_1​, γ) ∈ δ, (q_1​, q_2​) ∈ S, (q_2​, a, γ, q′) ∈ δ}.
                Тогда S′′ = {(q, q′) | ∃q_3​: (q, q_3​) ∈ S′, (q_3​, q′) ∈ Update}, R′′ = {q′ | ∃q ∈ R′, (q, q′) ∈ Update}.
            • Если a ∈ Σ_{ret}, то ((S, R), a, ⊥, (S′, R′)) ∈ δ′, если S′ = {(q, q′) | ∃q′′: (q, q′′) ∈ S, (q′′, a, ⊥, q′) ∈ δ}, R′ = {q′ | ∃q ∈ R: (q, a, ⊥, q′) ∈ δ}.
    
    Построенный VPA M' является детерминированным VPA (DVPA) по построению.

Примечания:
    - Id_Q = {(q, q) | q ∈ Q}.
================================================================
Приведи пример работы DVPA
________________________________________________________________
Пусть есть VPA M = ⟨\tilde{Σ}, Q, Q_{in}, Q_{F}, Γ, δ⟩ и его детерминированная версия DVPA M' (то есть M^{DET} = M').

Пусть есть слово w = w_1 a_1 w_2 a_2 w_3, причём w_1 ∈ MC(\tilde{Σ}), w_2, w_3 ∈ WM(\tilde{Σ}), a_1, a_2 ∈ Σ_{call}.

Рассмотрим, как DVPA M' будет разбирать слово w. Последовательность запусков ρ при разборе слова w будет равна:
((S_0, R_0), ⊥, w_1 a_1 w_2 a_2 w_3),
    - S_0 = {(q, q') | q \xrightarrow{ε} q', q, q' ∈ Q} = Id_Q
    - R_0 = {q | Q_{in} \xrightarrow{ε} q, q ∈ Q} = Q_{in}
((S_1, R_1), ⊥, a_1 w_2 a_2 w_3),
    - S_1 = {(q, q') | q \xrightarrow{w_1} q', q, q' ∈ Q}
    - R_1 = {q | Q_{in} \xrightarrow{w_1} q, q ∈ Q}
((S_0, R_2), (S_1, R_1, a_1)⊥, w_2 a_2 w_3),
    - R_2 = {q | Q_{in} \xrightarrow{w_1 a_1} q, q ∈ Q}
((S_2, R_3), (S_1, R_1, a_1)⊥, a_2 w_3),
    - S_2 = {(q, q') | q \xrightarrow{w_2} q', q, q' ∈ Q}
    - R_3 = {q | Q_{in} \xrightarrow{w_1 a_1 w_2} q, q ∈ Q}
((S_0, R_4), (S_2, R_3, a_2)(S_1, R_1, a_1)⊥, w_3),
    - R_4 = {q | Q_{in} \xrightarrow{w_1 a_1 w_2 a_2} q, q ∈ Q}
((S_3, R_5), (S_2, R_3, a_2)(S_1, R_1, a_1)⊥, ε),
    - S_3 = {(q, q') | q \xrightarrow{w_3} q', q, q' ∈ Q}
    - R_5 = {q | Q_{in} \xrightarrow{w_1 a_1 w_2 a_2 w_3} q, q ∈ Q}

Для понимания работы DVPA рассмотрим ещё несколько случаев:
    1) Пусть после чтения w DVPA M' прочитает ещё и символ a_3 ∈ Σ_{call}, тогда DVPA M' перейдёт в конфигурацию
    ((S', R'), (S_3, R_5, a_3)(S_2, R_3, a_2)(S_1, R_1, a_1)⊥, ε), где:
        - S' = S_0,
        - R' = {q | Q_{in} \xrightarrow{w_1 a_1 w_2 a_2 w_3 a_3} q, q ∈ Q}.
    
    2) Пусть после чтения w DVPA M' прочитает ещё и символ c ∈ Σ_{int}, тогда DVPA M' перейдёт в конфигурацию
    ((S', R'), (S_2, R_3, a_2)(S_1, R_1, a_1)⊥, ε), где:
        - S' = {(q, q') | q \xrightarrow{w_3 c} q', q, q' ∈ Q},
        - R' = {q | Q_{in} \xrightarrow{w_1 a_1 w_2 a_2 w_3 c} q, q ∈ Q}.
    
    3) Пусть после чтения w DVPA M' прочитает ещё и символ b_2 ∈ Σ_{ret}, тогда DVPA M' перейдёт в конфигурацию
    ((S', R'), (S_1, R_1, a_1)⊥, ε), где:
        - S' = {(q, q') | q \xrightarrow{a_2 w_3 b_2} q', q, q' ∈ Q},
        - R' = {q | Q_{in} \xrightarrow{w_1 a_1 w_2 a_2 w_3 b_2} q, q ∈ Q},
    причём S' просчитывается как композиция функций b_2 ∘ S_3 ∘ a_2 над S_2 (то есть последовательно применяем переходы к S_2).

Примечание:
    - По сути множество S состоит пар состояний q и q' таких, что  q \xrightarrow{w} q', где w -- WM-слово, прочитанное с последнего вызова.
    - По сути множество P состоит из состояний, достижимых из множества начальных состояний Q_{in} по прочитанной части слова. 
    - Id_Q = {(q, q) | q ∈ Q}.
    - Индекс 2 у символа b_2 выбран для того, чтобы наглядно показать, что данный символ закрывает вызов символа a_2.

Какова главная идея детерминизации VPA?
________________________________________________________________
Для построения детерминированного VPA можно было бы воспользоваться конструкцией подмножеств, которая используется для построения ДКА.
Однако здесь возникает проблема со стеком. Например, пусть в VPA есть два состояния q и q', причём считывая слово w можно прийти из q в q' с двумя различными конфигурациями
(то есть двумя способами): (q', AA⊥, ...) и (q', BB⊥, ...), тогда при построении конструкцией подмножеств мы можем получить стек следующего вида: (A|B)(A|B),
что не верно.

Для решения этой проблемы можно использовать следующее наблюдение:
При чтении WM-слов стек не изменяется, хотя, конечно, при чтении его подслов стек может изменяться.
Другими словами, после чтения WM-слова стек автомата будет точно таким же, как и до его чтения. 

Таким образом, главная идея детерминизации VPA заключается в следующем: 
Строится конструкция подмножеств, однако вместо того, чтобы сразу обрабатывать push-переходы (те, которые добавляют данные в стек), они запоминаются и обрабатывается
только тогда, когда происходит соответствующий pop-переход (то есть извлечение данных из стека). Таким образом, по сути, происходит обработка WM-слов.

В процессе этого подхода создаётся компонент S, который отслеживает, какие переходы между состояниями могут происходить от момента push-перехода до соответствующего pop-перехода. 
Благодаря этой информации обновляется список R состояний, которые можно достичь из начального на текущем этапе.

Что такое visibly pushdown grammar?
________________________________________________________________
Контекстно-свободная грамматика G = ⟨N, Σ, P, S⟩ называется visibly pushdown grammar с разбиением \tilde{Σ} (\tilde{Σ}-VPG),
если множество нетерминальных символов V можно разбить на два непересекающихся множества V_0 и V_1 так,
что все правила переписывания P находятся в одной из следующих форм:
    - X → ε,
    - X → aY, причём если X ∈ V_0, то a ∈ Σ_{int} и Y ∈ V_0,
    - X → aYbZ, причём a ∈ Σ_{call}, b ∈ Σ_{ret}, Y ∈ V_0 и если X ∈ V_0, то Z ∈ V_0.

Замечания:
    - Нетерминальные символы из множества V_0 порождают только WM-слова, а нетерминальные символы из множества V_1 могут порождать не только WM-слова, но MC-слова, а также MR-слова.
================================================================
Что такое well-matched visibly pushdown grammar?
________________________________________________________________
Контекстно-свободная грамматика G = ⟨N, Σ, P, S⟩ называется well-matched visibly pushdown grammar с разбиением \tilde{Σ} (\tilde{Σ}-WM-VPG),
если все правила переписывания P находятся в одной из следующих форм:
    - X → ε,
    - X → aY, где a ∈ Σ_{int},
    - X → aYbZ, где a ∈ Σ_{call} и b ∈ Σ_{ret}.
================================================================
Что такое WM-WPG?
________________________________________________________________
WM-VPG -- это тоже самое, что и well-matched visibly pushdown grammar.
================================================================
Как связаны VPL и VPG?
________________________________________________________________
Язык L ⊆ Σ^{*} является visibly pushdown language с разбиением \tilde{Σ} (\tilde{Σ}-VPL) тогда и только тогда, 
когда для него можно написать visibly pushdown grammar с разбиением \tilde{Σ} (\tilde{Σ}-VPG).

Как преобразовать VPA в VPG?
________________________________________________________________
Пусть есть VPA M = ⟨\tilde{Σ}, Q, Q_{in}, Q_{F}, Γ, δ⟩.

Построим \tilde{Σ}-VPG G = ⟨N, Σ, P, S⟩ следующим образом:
    1) Для каждого состояния q ∈ Q во множестве V_1 содержатся нетерминалы X_q и Y_q.
    Нетерминал X_q говорит о том, что автомат находится в состоянии q с пустым стеком.
    Нетерминал Y_q говорит о том, что автомат находится в состоянии q с непустым стеком, однако его содержимое нас не интересует.

    2) Для каждой пары состояний (q, p) ∈ Q × Q и стекового символа γ ∈ Γ во множестве V_0 содержится нетерминал Z_{q, γ, p}.
    Нетерминал Z_{q, γ, p} говорит о том, что автомат находится в состоянии q, на вершине стека находится символ γ и автомат должен быть в состоянии p 
    непосредственно перед снятием стекового символа с вершины стека.

    3) Добавим во множество правил переписывания следующие правила:
        1. Для каждого состояния q, если q ∈ Q_{F}, множество P содержит правила X_q → ε и Y_q → ε.

        2. Для каждого состояния q и символа стека γ, множество P содержит правило Z_{q, γ, q} → ε.

        3. Для каждого локального действия a и состояний q, p, если δ содержит переход (q, a, p), то множество P содержит правила X_q → aXp и Y_q → aYp.

        4. Для каждого локального действия a, состояний q, p, q' и символа стека γ, если δ содержит переход (q, a, p), то множество P содержит правило Z_{q, γ, q'} → aZ_{p, γ, q'}.

        5. Для каждого вызова a, возврата b, символа стека γ и состояний q, q', p, p', если δ содержит переходы (q, a, γ, p) и (q', b, γ, p'), то множество P содержит правила X_q → aZ_{p, γ, q'}bX_{p'} и Y_q → aZ_{p, γ, q'}bY_{p'}.

        6. Для каждого вызова a, возврата b, символов стека γ, γ' и состояний q, q', p, p', r, если δ содержит переходы (q, a, γ, p) и (q', b, γ', p'), то множество P содержит правило Z_{q, γ', r} → aZ_{p, γ, q'}bZ_{p', γ' ,r}.

        7. Для каждого вызова a, состояний q, p и символа стека γ, если δ содержит переход (q, a, γ, p), то множество P содержит правила X_q → aY_p и Y_q → aY_p.

        8. Для каждого возврата a и состояний q, p, если δ содержит переход (q, a, ⊥, p), то множество P содержит правило X_q → aX_p.

    4) Пусть множество Ss = {X_q | ∀q ∈ Q_{in}}. Для каждого правила переписывания (X → α) ∈ P, где X ∈ Ss, добавим в P правило переписывания S → α.

Построенная \tilde{Σ}-VPG G будет порождать тот же язык, что и распознаётся VPA M.

Как преобразовать VPG в VPA?
________________________________________________________________
Пусть есть \tilde{Σ}-VPG G = ⟨N, Σ, P, S⟩.

Построим VPA M = ⟨\tilde{Σ}, Q, Q_{in}, Q_{F}, Γ, δ⟩, где:
    - Q = N × {0, 1},
    - Q_{in} = (S, 1),
    - Q_{F} = {(X, 1) | (X → ε) ∈ P},
    - Γ = V × (Σ_{ret} × {0, 1}) ∪ $ × {0, 1} ∪ ⊥,
    - δ -- функция переходов, причём:
        • Если a ∈ Σ_{int}, то ∀X, Y ∈ N:
            - Если (X → aY) ∈ P, то ((X, f), a, (Y, f)) ∈ δ,
        • Если a ∈ Σ_{call}, то ∀X, Y ∈ N:
            - Если (X → aY) ∈ P, то ((X, f), a, (Y, 1), ($, f)) ∈ δ,
            - Если (X → aYbZ) ∈ P, то ((X, f), a, (Y, 0), (b, (Z, f))) ∈ δ,
        • Если a ∈ Σ_{ret}, то ∀X, Y ∈ N:
            - Если (X → aY) ∈ P, то ((X, 1), a, ⊥, (Y, 1)) ∈ δ и ((X, 1), a, ($, f), (Y, f)) ∈ δ,
            - Если (X → ε) ∈ P и X ∈ V_0, то ((X, f), a, (a, (Y, f')), (Y, f')) ∈ δ.

Построенный VPA M будет распознавать тот же язык L, что и пораждается \tilde{Σ}-VPG G.
================================================================
Теорема Майхилла-Нероуде для WM-VPL
________________________________________________________________
Язык L является \tilde{Σ}-VPL <=> \tilde{Σ}-VPL конгруэнция ≈ (well-matched) конечна (то есть имеет конечное множество классов эквивалентностей).
