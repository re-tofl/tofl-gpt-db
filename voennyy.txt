Теорема Сэвича о пространственной сложности вычислений
________________________________________________________________
Для любой функции f : N → R+ , где f(n) ≥ n, NSPACE(f(n)) ⊆ SPACE(f^2(n)),
где SPACE(f(n)) и NSPACE(f(n)) - классы пространственной сложности:
SPACE(f(n))={L ∣ L — язык, решаемый детерминированной машиной Тьюринга с пространственной сложностью O(f(n))},
NSPACE(f(n))={L ∣ L — язык, решаемый недетерминированной машиной Тьюринга с пространственной сложностью O(f(n))}

Теорема означает, что для любой функции f(n) ≥ n, задачи, решаемые недетерминированной машиной Тьюринга с использованием пространства, ограниченного f(n), также могут быть решены детерминированной машиной Тьюринга с использованием пространства, ограниченного f^2(n).

Теорема о рекурсии для машины Тьюринга
________________________________________________________________
Пусть T машина Тьюринга, которая вычисляет функцию t: Σ∗ × Σ∗ → Σ∗. Существует машина Тьюринга R, которая вычисляет функцию r: Σ∗ → Σ∗, такая что для любого w выполняется: r(w) = t(<R>, w), где <R>  - описание машины R, Σ∗ - множество всех возможных конечных слов над алфавитом Σ, w - слово из Σ∗
================================================================
Когда машина Тьюринга минимальна?
________________________________________________________________
Если M — машина Тьюринга, то длиной описания <M> назовём количество символов в строке, задающей M. Скажем, что машина M минимальна, если не существует эквивалентной ей машины Тьюринга с более коротким описанием. Обозначим MIN_TM = {<M> | M является минимальной машиной Тьюринга}

Алгоритм Маркова
________________________________________________________________
Алгоритм Маркова — это система, правила переписывания которой x → y рассматриваются как упорядоченные. В процессе вывода необходимо использовать первое применимое правило переписывания. Более того, самое левое вхождение подстроки x должно быть заменено на y. Некоторые из правил переписывания могут быть выделены как терминальные правила, они будут показаны как x →. y
Вывод начинается с некоторой строки w ∈ Σ и продолжается либо до использования терминального правила, либо до тех пор, пока не останется применимых правил переписывания.
Для принятия языка определяется множество T ⊆ Σ терминалов. Начав с терминальной строки, правила переписывания применяются до тех пор, пока не будет получена пустая строка, либо не будет применено терминальное правило.

Пусть M — марковский алгоритм с алфавитом Σ и терминалами T. Тогда множество L(M) = {w ∈ T* : w =>* λ} является языком, принимаемым M.

Рассмотрим пример с алфавитом Σ = T = {a, b} и правилами переписывания ab → λ, ba → λ.
Каждый шаг в выводе уничтожает подстроку ab или ba, поэтому L(M) = {w ∈ {a, b}* : n_a(w) = n_b(w)}.
================================================================
Найти алгоритм Маркова для языка L = {a^n b^n : n ≥ 0}
________________________________________________________________
Решение: ab → S, aSb → S, S →. λ
================================================================
Регулярна ли разность двух регулярных языков?
________________________________________________________________
Пусть L1, L2 регулярные языки. По определению разности множеств: L1 \ L2 = L1 ∩ ¬L2. Из регулярности L2 следует регулярность его дополнения ¬L2. Регулярные языки замкнуты относительно операции пересечения, поэтому L1 ∩ ¬L2 является регулярным языком. Таким образом, разность L1 \ L2 тоже является регулярным языком
================================================================
Какая грамматика порождает L = {a^n b^(n+1) : n ≥ 0}
________________________________________________________________
Решение: грамматика G = (V, T, S, P) с правилами переписывания P: S → Ab, A → aAb, A → ε порождает язык L, где V = {S, A} - алфавит нетерминалов, T = {a, b} - алфавит терминалов, S - стартовый нетерминал.
================================================================
Могут ли две грамматики из разных классов иерархии порождать один язык?
________________________________________________________________
Да, например, КЗ грамматика G1 = ({0,1}, {A,S}, P1, S) и КС грамматика G2 = ({0,1}, {S}, P2, S) с правилами 
P1: S → 0A1, 0A → 00A1, A → ε 
P2: S → 0S1 | 01

Где 0,1 - терминальные символы; A,S - нетерминальные символы; S - стартовый нетерминал.

Такие грамматики называются эквивалентными, обе порождают язык  L(G1) = L(G2) = {0^n 1^n | n>0}
================================================================
Являются ли все контекстно-свободные языки регулярными?
________________________________________________________________
Нет, только подмножество контекстно-свободных языков являются регулярными. Например, язык, образованный правильной скобочной последовательностью является контекстно-свободным, но не регулярным.
================================================================
Пример построения КС грамматики для языка
________________________________________________________________
Рассмотрим язык L={a^n b^m c^m d^n | n, m ≥ 1}
Решение:
S → aSd
S → A
A → bAc
A → bc

Наследуемый атрибут
________________________________________________________________
В атрибутных грамматиках наследуемый атрибут - атрибут, значение которого зависит от значений атрибутов братьев узла или атрибутов родителя.
