1. Определение системы типов (по Пирсу)
_______________________________________________________________________________________________________________________
Система типов — гибко управляемый синтаксический метод доказательства отсутствия в программе определенных видов
поведения при помощи классификации выражений языка по разновидностям вычисляемых ими значений.
=======================================================================================================================
2. Алгоритм Бурке-Фишера (восстановления после ошибки)
_______________________________________________________________________________________________________________________
 Значение k заранее задано.

 1) Парсер обнаруживает ошибку на i-ом терминале входа
 2) Необходимо рассмотреть все возможные последовательности
    терминалов от i-ого до i - k − 1-ого, продолжающие
    парсинг
 3) Выбираем в качестве «починки» ту из них,
    расстояние Левенштейна до которой от реального входа
    наименьшее.

=======================================================================================================================
3. Smn теорема Клини
_______________________________________________________________________________________________________________________
Для любого m, n >= 1 существует вычислимая функция S^m_n (называемая специализатором, частичным вычислителем)
такая что
∀p, x_i, y_i : [[p]](x_1, ... , x_m, y_1, ..., yn_) = [[[S^m_n]](p, x_1, ..., x_m)]](y_1, ..., y_n)
p -- код программы
[[x]] -- вычислимая функция, которую реализует программа с кодом x
x_1, ..., x_m -- фиксируемые аргументы
y_1, ..., y_n -- оставшиеся аргументы
S^m_n(p, x_1, ..., x_m) -- новая программа или функция, которая вычисляется из p и фиксированных аргументов x_1, ..., x_m
и принимает на вход только y_1, ..., y_n
=======================================================================================================================
4. Вторая теорема Клини о рекурсии
_______________________________________________________________________________________________________________________
Для любой программы p, которая принимает два аргумента (x и y), существует программа q, которая принимает один аргумент d
и выполняет то же самое, что и программа p, но с первым аргументом, равным коду самой программы q.

∀p ∃q ∀d: [[q]](d) = [[p]](q, d).
где
p -- код программы, принимающей два аргумента
q -- код программы, которая использует себя (рефлексирует) в вычислениях
d -- входные данные
=======================================================================================================================
5. Универсальные функции
_______________________________________________________________________________________________________________________
Функция U:NxN -> N ∪ {⊥} называется универсальной для класса вычислимых функций одного аргумента, если U_n(x)=U(n,x)
(«сечение» функции U при фиксированном n) является вычислимой функцией и для любой вычислимой функции f :
∃n ∈ N :f(x)=U(n,x)
=======================================================================================================================
6. Многоголовочные автоматы
_______________________________________________________________________________________________________________________
Односторонний недетерминированный k-головочный (multihead) автомат, NFA(k), это пятёрка A = (Σ, Q, q0, δ, F), состоящая из следующих компонентов.

- Σ — алфавит, не содержащий двух особых символов ⊢, ⊣ ∈/ Σ (меток начала и конца
строки).
- Q — конечное множество состояний.
- Q_0 ⊆ Q — множество начальных состояний.
- δ : Q × (Σ ∪ {⊢, ⊣})^k -> Q × 2^({0,+1}^k) — частичная функция переходов.
• F ⊆ Q — множество принимающих состояний.

Для входной строки w = a1 ... a_l ∈ Σ^*, пусть a0 = ⊢ и a_l+1 = ⊣. Вычисление NFA(k) на w — это самая длинная, возможно бесконечная, последовательность
(p0, i_1^(0), ..., i_k^(0)), ..., (p_j, i_1^(t), ..., i_k^(t)), ..., где:

- p_t ∈ Q и i_1^(t), ..., i_k^(t) ∈ {0, ..., l + 1} на каждом t-м шаге;
• начальная конфигурация — (q0, 0, ..., 0) для некоторого q_0 ∈ Q_0;
• всякая следующая конфигурация (p_t, i_1^(t), ..., i_k^(t)) если она определена, удовлетворяет:
i_j^(t) = i_j^(t-1) + d_j^(t), где δ(p_t-1, a_(i_1^(t)), ..., a_(i_k^(t))) ∋ (p_t, d_1^(t), ..., d_k^(t))

=======================================================================================================================
7. Детерминированный многоголовочный автомат
_______________________________________________________________________________________________________________________
k-головочный автомат — детерминированный, DFA(k), если |Q_0| = 1 и |δ(q, a1, ..., ak)| = 1 для
любых аргументов.

=======================================================================================================================
8. Теорема о распознаваемости языков многоголовочными автоматами
_______________________________________________________________________________________________________________________
Для всякого k ⩾ 1 существует язык, который распознаётся DFA(k + 1), но не распознаётся никаким NFA(k)
=======================================================================================================================
9. Теорема о существовании нормального вида Хробака для односимвольных NFA
_______________________________________________________________________________________________________________________
Для всякого односимвольного NFA существует NFA в нормальном виде Хробака
=======================================================================================================================
10. Нормальный вид Хробака для односимвольного NFA
_______________________________________________________________________________________________________________________
n -- количество состояний в исходном NFA
Нормальный вид Хробака односимвольного NFA -- односимвольный NFA, задающий тот же язык, и имеющий не более чем n^2 состояний
между начальным состоянием и единственным состоянием с недетерминированным выбором, ведущим к набору непересекающихся циклов, где в этих циклах
содержится не более n состояний суммарно.
=======================================================================================================================
11. Чередующийся конечный автомат (alternating finite automaton, AFA)
_______________________________________________________________________________________________________________________
Чередующийся конечный автомат(alternating finite automaton, AFA): A = (Σ, Q∃, Q∀, q0, δ, F), в которых Q_∃ ∩ Q_∀ = ∅ и
δ: Q x Σ -> 2^Q
- Строка ε принимается из состояния q, если q ∈ F.
- Строка aw принимается из состояния q ∈ Q_∃, если существует состояние q ∈ δ(q, a), из которого принимается w.
- Строка aw принимается из состояния q ∈ Q_∀, если для любого состояния q ∈ δ(q, a) строка w принимается из q.

Язык L(A) состоит из всех строк, принимающихся из состояния q0.
