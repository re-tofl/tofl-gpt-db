1. Сформулируй лемму Шаллита для детерминированных КС-языков.
_______________________________________________________________
Для всякого детерминированного КС языка (LR-языка) L ⊆ Σ∗ существует бесконечное множество M ⊆Σ∗, для которого для всякой строки w ∈ Σ∗ или все строки из Mw лежат в L, или ни одна из них не лежит.
То есть, существует бесконечный класс эквивалентности Майхилла–Нероуда.
Mw — это множество всех строк, которые эквивалентны строке w в рамках отношения эквивалентности Майхилла–Нероуда, то есть строки, которые не могут быть различены автоматом, который распознает язык L. Это множество строк, которые имеют одинаковое поведение с 
w относительно языка L.
===============================================================
2. Для чего используется лемма Шаллита для детерминированных КС-языков?
_______________________________________________________________
Лемма Шаллита позволяет исследовать структуру языка, выявляя бесконечные классы эквивалентности строк и, таким образом, доказывать, что определённый язык не может быть распознан DPDA или не является LR(k). Для этого:
1. Определяют множество M⊆Σ∗ с бесконечным числом элементов.
2. Показывают, что строки из этого множества не могут быть разделены на конечное число классов эквивалентности.
3. Используют это для вывода о невозможности существования LR(k)-грамматики для данного языка.
===============================================================
3. Доказательство леммы Шаллита для детерминированных контекстно-свободных языков.
_______________________________________________________________
Пусть L распознаётся некоторым детерминированным магазинным автоматом (DPDA). Рассмотрим произвольную строку x ∈ Σ∗. После её прочтения DPDA окажется в некотором состоянии q, а содержимое стека будет представлено последовательностью символов s₁ s₂ … sₖ.
Рассмотрим такое продолжение y, что после прочтения строки u = xy автомат перейдёт в состояние, при котором количество символов в стеке становится минимальным. Это минимальное состояние возможно благодаря тому, что автомат на эпсилон-переходах или входных символах может удалять символы из стека. После достижения этого состояния стек стабилизируется, то есть оставшиеся в стеке символы s₁′ s₂′ … sₘ′ (где m ≤ k) больше не будут удалены, какими бы ни были последующие входные символы.
Заметим, что таких строк u бесконечно много, поскольку длина строк x не ограничена, а продолжения y могут быть выбраны различными способами. Для каждой строки u определим состояние q, в котором окажется автомат после её прочтения, и символ s, находящийся на вершине стека. Поскольку множество состояний автомата и множество стековых символов конечны, по принципу Дирихле существует бесконечное подмножество строк u, после прочтения которых автомат оказывается в одном и том же состоянии q с одним и тем же верхним символом s в стеке.
Обозначим это подмножество как M. Для любой строки w (продолжения входной строки u), либо все строки из M⋅w принимаются автоматом, либо отвергаются. Это следует из детерминированности автомата: одинаковые состояния q и вершины стека s приводят к одному и тому же поведению автомата.
===============================================================
4. Множество палиндромов над алфавитом {a,b} является детерминированным КС-языком?
 _______________________________________________________________
Множество палиндромов над алфавитом {a,b} — не является детерминированным КС-языком (LR) по суффиксной конгруэнтности. Для него нет ни одного класса эквивалентности, состоящего более чем из одного элемента.
Нужно доказать, что никакие две различных строки u, v не могут попасть в один класс. Достаточно приписать к ним строку w = ((ba)^(|uv|))((bu)^(R)). Тогда ((uba)^(|uv|))((bu)^R) — палиндром, а ((vba)^(|uv|))((bu)^(R)) — уже нет. 
Действительно, чтобы строка ((vba)^(|uv|))((bu)^(R)) была палиндромом, середина палиндрома должна была бы находиться в центральном куске a^(|uv|). Тогда два символа b соответствовали бы друг другу, и далее u и v совпали бы.
===============================================================
5. Является ли строгая LL(k)-грамматика (k ≥ 1) однозначной грамматикой?
_______________________________________________________________
Грамматика называется однозначной, если у каждого слова имеется не более одного дерева разбора в этой грамматике.
Строгая LL(k) грамматика - подмножество грамматики LL(k), где дополнительно выполняется: 
1. Отсутствие перекрывающихся правил. Для каждого нетерминала A, если грамматика имеет два или более правила вида A → α 
и A→β, то первый символ каждой правой части этих правил должен быть различен. То есть, если α=aγ и β=bδ, то a ≠ b, где a и b - это первые символы строк α и β.
2. Строгая LL(k)-грамматика не допускает ситуаций, когда для некоторой строки существует несколько вариантов анализа (то есть она не является неоднозначной в пределах k-символьного окна).
По формулировке выше строгая LL(k)-грамматика совпадает с LL(1).

Если G = (N, T, P, S) - строгая LL(k)-грамматика (k >= 1), то G - однозначная грамматика.
===============================================================
6. Когда контекстно-свободная грамматика является строгой LL(1)-грамматикой в терминах множества LOOKAHEAD?
_______________________________________________________________
Контекстно свободная грамматика является строгой LL(1)-грамматикой тогда и только тогда, когда КС-грамматика является LL(1)-грамматикой.
Контекстно свободная грамматика G = (N, T, P, S) является строгой LL(1)-грамматикой тогда и только тогда, когда для любой пары несовпадающих продукций грамматики вида A → α и А → β, имеющих одинаковые левые части, справедливо следующее утверждение:
LOOKAHEAD(A→α) пересечь с LOOKAHEAD(А→β) дает пустое множество. 
===============================================================
7. Приведи пример удаления правил вида A → B или  <нетерминал> → <нетерминал> для получения эквивалентной грамматики для исходной КС-грамматики.
_______________________________________________________________
Эквивалентную грамматику, не содержащую правил вида А→В, где А и В – нетерминальные символы, можно построить для любой КС-грамматики.
Пусть имеется КС-грамматика G = (N, T, P, S) со множеством нетерминалов N = {A1, A2, ..., An}. Для построения эквивалентной КС-грамматики G' = (N, T, P', S), следует выполнить такие шаги:
1. Разделение множества правил P. Множество правил P разбивается на два непересекающихся подмножества: P1 - все цепные правила вида Ai → Ak, где Ai, Ak ∈ N, P2 - остальные правила (P2 = P \ P1).
2. Определение множества правил P(Ai). Для каждого Ai ∈ N определим множество P(Ai), которое включает все правила вида Ai → σ, где: σ ∈ T* (строчка из терминалов), существует цепной вывод Ai→* Aj, такой что Ai → σ, правило Aj → σ ∈ P2.
То есть P(Ai) заменяет цепные переходы Ai → Aj правилами, напрямую связывающими Ai с терминальными строками σ.
3. Формирование множества правил P'. Само множество P' определяется как P' = {∪(от i = 1 до n)P(Ai)}∪P2, то есть объединяет все "нецепные" правила из P2 и  дополнительные правила из P(Ai), которые устраняют цепные переходы.
4. Эквивалентная грамматика G'. Грамматика G' имеет ту же аксиому S, множество терминалов T и множество нетерминалов N, что и G. Множество правил P заменяется на P'. G' = (N, T, P', S).


Вариант из книжки.
Разобьем Р на два непересекающихся множества P = P1 ∪ P2. В P1 включены все цепные правила
 вида Ai → Ak, в P2 - все остальные, т. е. P2 = P \ P1, где "\" - разность множеств P и P1. Затем для каждого Ai определим множество правил P(Ai), включив в него все такие правила Ai → σ, что Ai → * Aj и Aj → σ, где Aj → σ, где Aj → σ ∈ P2. Построим эквивалентную КС-грамматику G' = (N, T, P, S), в которой множества терминальных и нетерминальных символов, а также аксиома совпадают с теми же объектами исходной грамматики G , а множество правил P' получено объединением правил множества P2 и правил P(Ai) для всех 1 <= i <=n: P' = {∪(от i = 1 до n)P(Ai)}∪P2.
===============================================================
8. Приведи грамматику, эквивалентную грамматике, заданной следующими правилами вывода:
S → aFb | A  
A → aA | B  
B → aSb | S  
F → bc | bFc  
_______________________________________________________________
Пусть задана грамматика G с такими правилами вывода:
S → aFb | A  
A → aA | B  
B → aSb | S  
F → bc | bFc  
Построим множества правил P2, P(S), P(A), P(B), P(F).
Для множества правил P2 получим следующие правила:
P2 = { S → aFb, A → aA, B → aSb, F → bc | bFc }
Учитывая, что S ⇒ A ⇒ B или S ⇒* A, S ⇒ B, где ⇒* — это непосредственная выводимость, правила для P(S) будут такими:
P(S) = { S → aA, S → aSb }
Принимая во внимание, что A ⇒ B ⇒ S или A ⇒* B, A ⇒ S, правила для P(A) будут:
P(A) = { A → aSb, A → aFb }
Так как B ⇒ S ⇒ A или B ⇒* S, B ⇒* A, правила для P(B) будут:
P(B) = { B → aFb, B → aA }
Так как непосредственно выводимых нетерминалов не существует, правила для P(F) следующие: P(F) = ∅
Объединив полученные правила, можем записать эквивалентную исходной грамматику G':
S → aFb | aSb | A  
A → aA | aSb | aFb  
B → aA | aSb | aFb  
F → bc | bFc
P2 — это множество правил исходной грамматики G; P(S) — это множество правил, полученных из грамматики для нетерминала S, исходя из того, что S может быть выведен в другие нетерминалы через цепочки выводов; P(A) — множество правил, полученных для нетерминала A; P(B), P(F) — аналогично.

9. Сформулируй теорему, которая связывает понятие леворекурсивной грамматики с эквивалентным конечным автоматом.
_______________________________________________________________
Для каждой леворекурсивной грамматики существует эквивалентный конечный автомат.
Докажем:
Пусть дана леворекурсивная грамматика G с нетерминалами N, терминалами T, начальной аксиомой S и правилами вывода. Мы строим конечный автомат A, эквивалентный грамматике G, следующим образом:
1. Каждому нетерминальному символу грамматики ставим в соответствие состояние конечного автомата. Состояние, соответствующее аксиоме S, делаем заключительным. Также добавляем одно начальное состояние N, которое будет начальным состоянием автомата.
2. Для каждого правила грамматики A → B a, где a — терминальный символ, добавляем переход из состояния A в состояние B при чтении символа a.
3. Также добавляем переходы из начального состояния N в состояния, соответствующие начальным нетерминалам каждого правила, с чтением символа a (если правило имеет вид A → a) или переход через промежуточные состояния, если правило рекурсивное.
4. Переходы для всех правил грамматики должны быть построены аналогично, причем последовательность переходов будет соответствовать процессу вывода в грамматике. Таким образом, для любого вывода в грамматике S → A₁ aₖ → A₂ aₖ₋₁ → …, ему будет соответствовать последовательность команд автомата:
   N a₁ → Aₖ; Aₖ aₖ₋₁ → Aₖ₋₁; …; A₁ a₁ → S
Таким образом, язык, порождаемый грамматикой G, совпадает с языком, принимаемым конечным автоматом A, то есть L(G) = L(A).
Следовательно, для каждой леворекурсивной грамматики существует эквивалентный конечный автомат.

10. Дана грамматика G = (T, N, P, S), где T = {a, b},  N = {S},  P = { S → aSb, S → ab }.
Необходимо определить язык, порождаемый этой грамматикой.
_______________________________________________________________
Используя рекурсию, выведем несколько цепочек языка, порождаемого данной грамматикой:
S → ab,  
S → aSb → aabb,  
S → aSb → aaSbb → aaabbb, ...
После этого определим язык, порожденный данной грамматикой:
L(G) = {a^n b^n | n > 0}.

11. Описать язык, который порождается правилами S → bSS | a
_______________________________________________________________
Построим несколько терминальных цепочек, применяя заданные правила вывода:
S → a,
S → bSS → baa,
S → bSS → bbSSS → bbaaa,
S → bSS → bbSSbSS → bbaabaa,
S → bSS → bbSSbSS → bbbSSbSSbbSSbSS → ... .
Из полученных цепочек видно следующее:
а) цепочки, кроме аксиомы, всегда начинаются с терминала b и заканчиваются терминалом a;
б) количество терминалов a в любой цепочке всегда на 1 больше, чем количество b;
в) У посленего терминала b в конкретной терминальной цепочке должно быть как минимум два терминала а, так как каждый b порождает две новые независимые ветви которые потом завершаются a.
Исходя из этих выводов, определим язык, порождаемый заданными правилами, в виде:
L(G) = {α | α ∈ {a, b}*, |a| = |b| + 1},
причем цепочки начинаются с терминала b и заканчиваются терминалом a, где у посленего терминала b в конкретной терминальной цепочке должно быть как минимум два терминала а, так как каждый b порождает две новые независимые ветви которые потом завершаются a.
